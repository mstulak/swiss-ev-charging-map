# Swiss EV charging prices map

Interactive map of public EV chargers in Switzerland with prices (CHF/kWh), plus an FSD & roaming overview tab.

- Stations: BFE ich-tanke-strom (federal data), plus OpenStreetMap and Open Charge Map for sites not in the BFE list.
- Prices: Swiss eMobility open data (opendata.swiss, BY ASK, non-commercial use), and operator websites (IONITY, Shell Recharge, ...).
- Official vs inferred prices are flagged on the map. Tesla Supercharger prices are unverified/inferred (tesla.com blocks automated access).
- Tick "only IONITY · Tesla · Shell Recharge" to isolate those networks.

Live: https://mstulak.github.io/swiss-ev-charging-map/
